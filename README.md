## keys

| key | action |
| --- | --- |
| R | reset (both games) |
| D | dark mode |
| M | rope game: mode, tomato game: sound on/off |
| 1-5 | tomato game: pick tomato / pie / brick etc / random |
| Esc / Q | back to the home page |
